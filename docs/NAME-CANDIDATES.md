# Name candidates: soft, ownable, defines hue/undertone/palette

Brief: short, soft/beauty feel, ideally an African or Arabic word (ties to BantuBloomNetwork's roots + the deep-skin-first mission), ownable (avoid the Oula/Oura/Zuri collision trap). The name should *mean* what the product reads: colour / hue / skin / glow.

## Lead candidate
- **Rangi**: Swahili for **"colour"**. Says exactly what the product does; soft, two syllables, African-rooted (on-brand for BantuBloomNetwork and the deep-skin-first mission). Web screen: only a small unrelated merch brand ("Rangi Merch"); appears clear in beauty/app. ✅ Recommend as lead. (To do: USPTO/EUIPO/WIPO + domain + app-store + handle check before locking.)

## Strong alternates (need the same collision screen)
| Name | Language / meaning | Feel | Note |
|---|---|---|---|
| **Uzuri** | Swahili "beauty" | soft, 3 syl | screen, "Zuri" family is crowded in beauty, "Uzuri" less so |
| **Alwan** | Arabic "colours" (ألوان) | soft, exact | pretty, plural of *lawn* (colour); screen |
| **Ngozi** | Swahili/Igbo "skin" (Igbo: "blessing") | warm, on-message | but a very common personal name → brand confusion |
| **Loun** | from Arabic *lawn* "colour", respelled | soft, one syllable | avoids the "lawn" English homograph; coined-feel, likely ownable |
| **Melia** | soft/coined (honey, ash-tree) | gentle, pretty | not literal but on-vibe; screen |

## Ruled out
- **Oula**: collides with Oula Health (funded women's-health startup) + Oura (ring). See NAME-OULA.md.
- **Zuri**: multiple beauty/cosmetics brands already (one African-founded, $5M raised). Swahili "beautiful".
- **Aurora K**: the user's call: too long + too common for a product brand. Stays as the co-company, not the product.

## Recommendation
Lead with **Rangi**. It's the rare name that is short, soft, means "colour", carries the African/Global-South identity that is the mission's soul, and screens clean so far. Screen it properly (trademark classes 3 cosmetics / 9+42 software / 44 beauty, plus rangi.app or getrangi / domains + IG/TikTok handles) before the Blitz submission; keep Uzuri, Alwan, Loun as backups in the same screening pass.

Company line for the paper: **built by BantuBloomNetwork × Aurora K.**
