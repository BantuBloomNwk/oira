# Name decision: OIRA (locked 2026-07-04)

**Product name: Oira** ("OY-ra"). By BantuBloomNetwork × Aurora K.

## Meaning
Coined from **Iris**: the goddess of the rainbow and the coloured ring of the eye. The rainbow is the full spectrum (every shade, deep tones centered, no "light" end privileged); the iris is where colour lives in a face. *Every hue, held in her.* It also echoes *golden* (Galician *oira/ouro*), a warm glow, never "lightening." Reads as a soft feminine name with the ring of Oula/Nua.

## Why coined
~40 real and near-coined names were screened across a dozen languages (Arabic, Swahili, Sanskrit, Persian, Korean, Japanese, Yoruba, Polynesian, Turkish, Latin, coined). Beauty is the most name-saturated consumer category; every short, soft, meaningful word was already a brand (Oula→Oula Health; Zuri, Sundus, Kanti, Jouri, Zia, Naz, Iro, Nua, Saya, Rona, Suna, etc., all taken; Tayf clean in beauty but a Gulf government project). The four constraints {3–4 letters, soft ring, real meaning, clear in beauty} cannot all hold with an existing word, so we coined one. Oira came back clean.

## Screen status
- Web + beauty search: **no direct collision** (nearest: Oria Skin, Eira, Oerra, all different).
- Copilot corpus (Solana hackathons): clear.
- **Still required before public launch:** formal trademark search in the relevant classes (3 cosmetics, 9/42 software, 44 beauty/health services) + domain (oira.app / getoira / tryoira) + IG/TikTok handle check + counsel. A clean web screen is a start, not clearance.
